# Accesso con Token/OTP

E' possibile gestire i token di accesso da Strumenti/Gestione accessi/Accesso con Token/OTP

Per aggiungere un nuovo token è sufficiente cliccare sul tasto \[+]

<figure><img src="../../../../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>

Per il nuovo token è possibile definire:

* Descrizione
* Valido dal
* Valido al
* Tipo di accesso
* Utente
* Modulo (tra quelli abilitati)
* ID record
* Permessi, a scelta tra
  * Lettura
  * Lettura e scrittura
  * Caricamento allegati
  * Caricamento e modifica allegati
