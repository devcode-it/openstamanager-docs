# Categorie file

Dal modulo categorie file è possibile gestire le categorie associate ai file allegati.

E' possibile creare una nuova categoria di file cliccando sul tasto ![](<../../../../.gitbook/assets/immagine (22).png>)

Sarà da qui possibile definire una descrizione e cliccare su Aggiungi

<figure><img src="../../../../.gitbook/assets/immagine (23).png" alt=""><figcaption></figcaption></figure>

Questa categoria sarà ora selezionabile al momento del caricamento di allegati.

{% hint style="info" %}
Tutti gli allegati senza categoria verranno raggruppati in una categoria di default denominata Generale.
{% endhint %}
