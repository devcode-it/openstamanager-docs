# Marche

E' possibile creare una nuova marca cliccando sul tasto ![](<../../../../.gitbook/assets/immagine (8).png>)

<figure><img src="../../../../.gitbook/assets/immagine (9).png" alt=""><figcaption></figcaption></figure>

Cliccando su Aggiungi la schermata si aprirà sulla nuova marca creata, dove sarà possibile modificare:

* Immagine
* Nome
* Link produttore
* Se articolo
* Se impianto
* Aggiungere modelli
