# 🔨 Strumenti

{% hint style="info" %}
Il modulo **Strumenti** permette di configurare le impostazioni del gestionale.
{% endhint %}

## Navigazione

Il modulo è raggiungibile dal menu laterale del gestionale, sotto il link **Strumenti**.

<figure><img src="../../../.gitbook/assets/immagine (1301).png" alt=""><figcaption></figcaption></figure>

## Interfaccia

Nel menu a tendina è possibile trovare i seguenti moduli:

* Stato dei servizi
* Viste
* Utenti e permessi
* Impostazioni
* Tabelle
* Campi personalizzati
* Import
* Segmenti
* Checklists
* Stampe
* Adattatori di archiviazione
* Gestione task
* Backup
* Aggiornamenti

<figure><img src="../../../.gitbook/assets/immagine (1302).png" alt=""><figcaption></figcaption></figure>
