# Fatture di acquisto

{% hint style="info" %}
Il modulo **Fatture di acquisto** permette di gestire la fatturazione in entrata dell'azienda.
{% endhint %}

<figure><img src="../../../../.gitbook/assets/immagine (1367).png" alt=""><figcaption></figcaption></figure>

## Creazione

Per registrare una nuova Fattura di acquisto si dovrà cliccare sul tasto (+).

Andranno qui inserite le informazioni relative alla nuova fattura di acquisto:

* Numero fattura del fornitore
* Data
* Fornitore
* Tipo documento
* Sezionale

<figure><img src="../../../../.gitbook/assets/immagine (1368).png" alt=""><figcaption></figcaption></figure>

## Modifica

Cliccando sul record da modificare si aprirà la schermata di dettaglio, da cui sarà possibile modificare:

* Fornitore
* Referente
* Numero fattura/protocollo
* Numero fattura del fornitore
* Data emissione
* Data registrazione
* Data competenza
* Sede partenza
* Sede destinazione
* Tipo documento
* Pagamento
* Banca accredito
* Banca addebito
* Split payment
* Ritenuta previdenziale
* Ritenuta pagata dal fornitore
* Note
* Note interne

<figure><img src="../../../../.gitbook/assets/immagine (1369).png" alt=""><figcaption></figcaption></figure>

* Righe
  * Articolo
  * Riga generica
  * Descrizione
  * Sconto/maggiorazione
  * DDT
  * Ordine
* Allegati

<figure><img src="../../../../.gitbook/assets/immagine (1370).png" alt=""><figcaption></figcaption></figure>

## Plugin

Selezionando uno specifico record si può accedere a diversi plugin nella barra laterale della pagina:

* Movimenti contabili
* Registrazioni
* Note interne
* Info
