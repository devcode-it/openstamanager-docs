# DDT in uscita

{% hint style="info" %}
Il modulo **DDT in uscita** permette di creare un documento di trasporto per la merce in uscita.
{% endhint %}

<figure><img src="../../../../.gitbook/assets/immagine (1399).png" alt=""><figcaption></figcaption></figure>

## Creazione

Per creare un nuovo DDT in uscita si dovrà cliccare sul tasto (+).

Andranno qui inserite le informazioni relative al nuovo DDT:

* Data
* Destinatario
* Causale di trasporto
* Sezionale

<figure><img src="../../../../.gitbook/assets/immagine (1397).png" alt=""><figcaption></figcaption></figure>

## Modifica

Cliccando sul record da modificare si aprirà la schermata di dettaglio, che presenta diverse sezioni:

#### Dati destinatario

* Destinatario
* Agente
* Referente

#### Intestazione

* Numero secondario
* Data
* Sede partenza
* Sede destinazione
* Pagamento
* Sconto in fattura

#### Dati ddt

* Aspetto beni
* Causale trasporto
* Tipo di spedizione
* Numero colli
* Porto
* &#x20;Vettore
* Data ora trasporto
* Peso
* Modifica peso
* Volume
* Modifica volume
* Note
* Note aggiuntive

#### Righe

#### Allegati

<figure><img src="../../../../.gitbook/assets/immagine (1398).png" alt=""><figcaption></figcaption></figure>

E' inoltre possibile modificare le righe e gli allegati.

Nelle righe è possibile inserire:

* Articolo
* Riga generica
* Descrizione
* Sconto/maggiorazione
* DDT
* Ordine

<figure><img src="../../../../.gitbook/assets/immagine (1029).png" alt=""><figcaption></figcaption></figure>
