# DDT in entrata

{% hint style="info" %}
Il modulo **DDT in Entrata** permette di registrare un documento di trasporto per la merce in entrata.
{% endhint %}

<figure><img src="../../../.gitbook/assets/immagine (148).png" alt=""><figcaption></figcaption></figure>

## Creazione

Per creare un nuovo DDT in entrata si dovrà cliccare sul tasto (+).

Andranno qui inserite le informazioni relative al nuovo DDT:

* Data
* Mittente
* Causale di trasporto
* Sezionale

<figure><img src="../../../.gitbook/assets/immagine (1421).png" alt=""><figcaption></figcaption></figure>

### Modifica

Cliccando sul record da modificare si aprirà la schermata di dettaglio, dove sarà possibile trovare diverse sezioni:

#### Dati mittente

* Mittente
* Referente

#### Intestazione

* Numero ddt
* Numero secondario
* Data&#x20;
* Sede partenza
* Sede destinazione
* Pagamento
* Sconto in fattura

#### Dati ddt

* Aspetto beni
* Causale trasporto
* Tipo di spedizione
* Numero colli
* Porto
* Vettore
* Data ora trasporto
* Note
* Note aggiuntive

#### Righe

Le righe possono includere:

* Articolo
* Riga manuale
* Descrizione
* Sconto/maggiorazione
* DDT
* Ordine
