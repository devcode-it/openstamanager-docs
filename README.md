# 📣 Novità

Di seguito le principali novità della versione 2.6, per maggiori dettagli visitare [GitHub](https://github.com/devcode-it/openstamanager).

➡️  Nuovo modulo **Marchi**, raggiungibile in Strumenti/Tabelle/Marchi, per definire una lista di marchi articolo e relativo link per aprire direttamente il sito del produttore dalla scheda articolo. E' stato inoltre aggiunto il campo **Modello**.

<figure><img src=".gitbook/assets/immagine (1114).png" alt=""><figcaption></figcaption></figure>

➡️  Nuovo modulo **Stati dei DDT**, raggiungibile in Strumenti/Tabelle/stati dei DDT\


<figure><img src=".gitbook/assets/immagine (1115).png" alt=""><figcaption></figcaption></figure>

➡️  Nuovo plugin **Mandati SEPA** del modulo Banche

<figure><img src=".gitbook/assets/immagine (1116).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunte le funzionalità di chiamata e invio mail sui campi di tipo telefono e email, per avviare una chiamata e la scrittura di un'email direttamente al click sulla cella:

<figure><img src=".gitbook/assets/immagine (1117).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunta la gestione dei pulsanti precedente e successivo nei vari moduli, in base al filtro della vista:

<figure><img src=".gitbook/assets/immagine (1118).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunto plugin **Importazione FE** per le fatture di vendita, è ora possibile importare file zip con le proprie fatture di vendita direttamente a gestionale, scegliendo tra importazione automatica o manuale grazie all'impostazione **Metodo di importazione XML fatture di vendita**

<figure><img src=".gitbook/assets/immagine (1119).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunta la gestione del **sottoscorta per sede** e aggiornamento quantità da plugin Giacenze

<figure><img src=".gitbook/assets/immagine (1120).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunte **Categorie** e **Sottocategorie** nei **Contratti,** raggiungibili da Strumenti/Tabelle/Categorie contratti:

<figure><img src=".gitbook/assets/immagine (1121).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunta controllo per conti non corrispondenti alle relative ragioni sociali delle anagrafiche collegate, tra gli strumenti di controllo del gestionale.

➡️  Aggiunta l'**eliminazione massiva** di interventi con righe non evase in altri documenti, e fatture non inviate allo SDI o via email

<figure><img src=".gitbook/assets/immagine (1122).png" alt=""><figcaption></figcaption></figure>

➡️  Aggiunta gestione **Impostazioni per utente**, al momento disponibile per le impostazioni&#x20;

* Nascondere la barra sinistra di default
* Nascondere la barra dei plugin di default
* Inizio periodo calendario
* Fine periodo calendario
* Sistema di firma

<figure><img src=".gitbook/assets/immagine (1124).png" alt=""><figcaption></figcaption></figure>

➡️  Ottimizzato il caricamento delle righe dei documenti, con controllo sull'evasione delle righe e sui documenti collegati

<figure><img src=".gitbook/assets/immagine (1123).png" alt=""><figcaption></figcaption></figure>
