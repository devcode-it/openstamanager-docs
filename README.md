# 📣 Novità

Di seguito le principali novità della versione 2.6, per maggiori dettagli visitare [GitHub](https://github.com/devcode-it/openstamanager).

➡️  Nuovo modulo **Marchi**

➡️  Nuovo modulo **Stati dei DDT**

➡️  Nuovo plugin **Mandati SEPA**

➡️  Aggiunte le funzionalità di chiamata e invio mail sui campi di tipo telefono e email

➡️  Aggiunta la gestione dei pulsanti precedente e successivo nei documenti

➡️  Aggiunto il campo Modello in **Articoli**

➡️  Aggiunta la gestione della Spedizione, Porto e Vettore in ordini

➡️  Aggiunto plugin **Importazione della fattura elettronica ciclo attivo**

➡️  Aggiunta la gestione del **sottoscorta per sede** e aggiornamento quantità da plugin Giacenze

➡️  Aggiunte **Categorie** e **Sottocategorie** nei **Contratti**

➡️  Aggiunta controllo piano dei conti collegato alle anagrafiche

➡️  Aggiunta l'**eliminazione massiva** di interventi con righe non evase in altri documenti, e fatture non inviate allo SDI o via email

➡️  Aggiunta gestione **Impostazioni per utente**

➡️  Ottimizzato il caricamento delle righe dei documenti, con controllo sull'evasione delle righe e sui documenti collegati
